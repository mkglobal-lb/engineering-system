# Agent Commands — قاموس أوامر Code Agent

Use consistent verbs so your intent is clear.

## INVESTIGATE
Understand the actual system before changing it.
**عندما تريد معرفة السبب الحقيقي قبل التعديل.**

## PLAN
Propose the implementation/design and trade-offs before coding.
**للتصميم قبل التنفيذ.**

## IMPLEMENT
Make the approved/justified change.
**للتنفيذ.**

## VERIFY
Run real checks that prove the change works.
**لإثبات النتيجة.**

## REVIEW
Critically inspect a change for correctness and risks.
**لمراجعة الكود/التغيير.**

## AUDIT
Compare the current system against an explicit standard/source of truth and identify gaps.
**للتدقيق الشامل مقابل مرجع واضح.**

## REPRODUCE
Demonstrate the failure/behavior reliably.
**لإعادة المشكلة وإثباتها.**

## REFACTOR
Improve structure without intentional behavior change.
**لتحسين البنية بدون تغيير behavior.**

## MIGRATE
Change schema/data/configuration through a controlled transition.
**لتغييرات migration.**

## HARDEN
Strengthen reliability/security/edge-case handling without changing the core feature intent.
**لتقوية الموجود.**

## RECONCILE
Compare multiple records/sources and explain discrepancies using a canonical source.
**مهم للبيانات والمال والمخزون.**

## PROFILE
Measure performance before optimizing.
**لا تحسين performance بالتخمين.**

## RELEASE
Prepare and validate production delivery.
**للنشر.**

## ROLLBACK / RECOVER
Return to a safe state or restore correctness.
**للرجوع/التعافي.**

## DOCUMENT
Record durable facts, decisions, contracts, or operational knowledge.
**للتوثيق الدائم، لا لتكرار الكود.**
